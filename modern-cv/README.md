# Modern CV Prototype

This directory contains a modern Astro-based CV prototype for Sangjae Lee.

## Commands

- `npm install`
- `ASTRO_TELEMETRY_DISABLED=1 npm run dev`
- `ASTRO_TELEMETRY_DISABLED=1 npm run build`

## Notes

- The current GitHub Pages site is still powered by the root Jekyll app.
- This Astro app is a parallel prototype and does not change deployment yet.
- Content is currently stored in `src/data/cv.ts` for a fast prototype.
