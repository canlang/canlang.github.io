# Sangjae Lee - Academic CV & Research Portfolio

Modern academic CV and engineering portfolio website powered by **Astro 5.x + TypeScript**.

🌐 **Live Site**: [https://research.studiosjlee.com](https://research.studiosjlee.com)

## Tech Stack
- **Framework**: [Astro 5.x](https://astro.build/) (Static Site Generator, Zero JS by default)
- **Language**: TypeScript
- **Hosting**: GitHub Pages via GitHub Actions
- **Custom Domain**: `research.studiosjlee.com`

## Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

## Content Management
CV and research data (experience, education, publications, patents, awards) are maintained in [`src/data/cv.ts`](src/data/cv.ts).
PDF CV and static assets are located in [`public/`](public/).
